NETRUNNER RISING — How to Install on iPhone & iPad
=================================================

This is a Progressive Web App (PWA). It does not go through the App Store.
You host the files online (once), then “Add to Home Screen” so it runs fullscreen and works offline.

────────────────────────────────────────
OPTION A: Easiest — Use the prepared GitHub Pages link
────────────────────────────────────────
(If the site is already live at the address below)

1. On your iPhone or iPad, open Safari (must use Safari, not Chrome or other browsers).
2. Go to:
   https://insightjokes.github.io/Netrunner-Rising/
3. Tap the Share button (square with arrow pointing up) at the bottom of the screen.
4. Scroll down and tap “Add to Home Screen”.
5. Edit the name if you want, then tap “Add” in the top-right corner.
6. A Netrunner icon will appear on your Home Screen. Tap it to launch the game fullscreen.

The home-screen version has its own saves, separate from the regular Safari tab.

────────────────────────────────────────
OPTION B: Host it yourself (recommended if the link above is not working)
────────────────────────────────────────
You only need to do this once. Free options: GitHub Pages or Neocities.

── Method 1: GitHub Pages (what the included README expects) ──

1. Unzip NetrunnerRising-iOS-WebApp.zip on a computer.
2. Create or open the GitHub repository:
   https://github.com/InsightJokes/Netrunner-Rising
3. Upload every file and folder from the zip into the root of the repo:
   • index.html
   • sw.js
   • manifest.webmanifest
   • icons/ (folder with the three PNG files)
   • fonts/ (folder with the .woff2 files)
4. In the GitHub repo go to: Settings → Pages
5. Under “Build and deployment” set:
   • Source: Deploy from a branch
   • Branch: main
   • Folder: / (root)
6. Click Save. Wait 1–2 minutes.
7. The game will be live at:
   https://insightjokes.github.io/Netrunner-Rising/
8. Follow the “Add to Home Screen” steps from Option A above.

── Method 2: Neocities (you already use this for Netrunner Rising) ──

1. Unzip the file on a computer.
2. Log in to your Neocities account.
3. Upload all the files and folders (index.html, sw.js, manifest.webmanifest, icons/, fonts/) into the root of your site (or into a subfolder if you prefer).
4. Note the URL of the page (example: https://netrunnerrising.neocities.org/ or whatever path you used).
5. Open that exact URL in Safari on your iPhone/iPad.
6. Tap Share → Add to Home Screen → Add.

────────────────────────────────────────
Important Notes
────────────────────────────────────────
• Must use Safari. Chrome, Firefox, etc. on iOS do not support “Add to Home Screen” the same way.
• After adding to the Home Screen the app runs fullscreen and works offline (thanks to the service worker).
• Saves are stored on the device and are separate from the browser version and from any Android version.
• To update the game later, re-upload the new files to the same location and refresh the Home Screen app (or remove and re-add it).

That’s it — once it’s on your Home Screen you can launch Netrunner Rising like any other app.

NETRUNNER RISING for Windows (10 and 11, 64-bit)

PLAY
1. Download NetrunnerRising.exe and double-click it. No installer needed.
2. The first time, Windows SmartScreen may say "Windows protected your PC" because the game isn't signed
   with a paid code-signing certificate. Click "More info", then "Run anyway".
3. The game opens in its own window. Press F11 for fullscreen.

It uses Microsoft Edge, which comes with Windows 10 and 11 (Google Chrome also works). Nothing else to install.

SAVES AND UPDATES
- Saves are kept in %LOCALAPPDATA%\NetrunnerRising and survive updates.
- Every launch checks netrunnerrising.neocities.org for a newer version and downloads it in the background.
  The new version opens the next time you start the game.

Tip: right-click NetrunnerRising.exe > Send to > Desktop (create shortcut).
